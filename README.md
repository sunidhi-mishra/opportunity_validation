## What this is

This repository contains my submission for Assignment 02 of the Ayuda Flagship Program: **Validate the Opportunity**.

The assignment asks a PM to take a product feature brief, build a structured validation plan around it, and set up the research infrastructure needed to turn interviews and design sessions into a go/no-go decision.

---

## The feature

**Round-Up Investing** — a proposed feature for a UPI + investing app (8M MAU).

Every UPI payment a user makes is rounded up to the next ₹10. The spare change is automatically invested into a low-risk fund. The pitch: convert payment-only users into first-time investors through a passive, zero-decision mechanic.

## Submission structure

The assignment is organised across four parts:

- **Part A** — Strategic fit, user value hypothesis, and business value hypothesis
- **Part B** — Six user personas, recruitment funnel, staged interview guide with rewritten questions
- **Part C** — Method selection (interview + design method), three-knob setup, stimulus spec, and design session run-sheet
- **Part D** — Refine-user-value template: hypothesis table, persona table, per-hypothesis validation blocks, final decision criteria, and Google Drive connector
